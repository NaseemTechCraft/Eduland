# Eduland

## Overview

Eduland is a responsive educational landing page built to present an engaging learning platform for students and visitors. It showcases courses, departments, and key services with a modern layout and mobile-first design.

## Features

- Responsive layout for desktop and mobile devices
- Hero section with a clear call-to-action
- About section to highlight mission and offerings
- Department cards for education categories
- Sticky navigation with mobile-friendly menu toggle
- Modern UI styling with custom fonts and clean sections

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Open `Index.html` in your browser.

## Usage

Open `Index.html` to view the Eduland landing page. Use it as a template for educational websites, course promotion, and academy or tutoring service presentations. Update the text, images, and links to reflect your institution and offerings.
